A pixel office for your Claude Code sessions ออฟฟิศพิกเซลของ Claude Code ทุก session

Every session you run becomes a worker at a desk. See at a glance who's busy, who's stuck waiting for your answer, and click anyone to jump straight to their terminal.

ทุก session ที่คุณเปิดจะกลายเป็นพนักงานหนึ่งคนในออฟฟิศ ดูได้ทันทีว่าใครกำลังทำงาน ใครรอคุณตอบอยู่ แล้วคลิกที่ตัวละครเพื่อกระโดดไปที่เทอร์มินัลของ session นั้นได้เลย

Get startedเริ่มใช้งาน

You need a Mac with Claude Code installed. Setup takes about two minutes.

ต้องใช้ Mac ที่ติดตั้ง Claude Code แล้ว ใช้เวลาตั้งค่าประมาณ 2 นาที

  1. Install Bunติดตั้ง Bun

    Deskbit runs on Bun. Skip this if bun --version already works.

    Deskbit รันบน Bun ถ้าพิมพ์ bun --version แล้วขึ้นเลขเวอร์ชันอยู่แล้ว ข้ามขั้นนี้ได้เลย

    curl -fsSL https://bun.sh/install | bash

  2. Download Deskbitดาวน์โหลด Deskbit

    Free, from GitHub. Unzip it anywhere.

    โหลดฟรีจาก GitHub แล้วแตกไฟล์ไว้ที่ไหนก็ได้

    Download for macOSดาวน์โหลดสำหรับ macOS

    Latest version: 1.0.2. See what's new

    เวอร์ชันล่าสุด 1.0.2 ดูว่ามีอะไรใหม่

  3. Start the officeเปิดออฟฟิศ

    cd deskbit
bun install
bun start

  4. Open itเปิดดู

    Go to localhost:7777, then run claude in any terminal. Your first worker walks in within a second.

    เข้า localhost:7777 แล้วเปิด claude ในเทอร์มินัลไหนก็ได้ พนักงานคนแรกจะเดินเข้ามาภายในวินาทีเดียว

Keep it running in the backgroundให้รันเบื้องหลังตลอด

Start Deskbit at login so the office is always one tab away:

ให้ Deskbit เปิดเองทุกครั้งที่ล็อกอิน จะได้เปิดแท็บดูได้ตลอด

zsh scripts/autostart.sh install

To stop it, run the same command with uninstall.

ถ้าจะเลิกใช้ รันคำสั่งเดิมแต่เปลี่ยนเป็น uninstall

Stays on your machineข้อมูลอยู่ในเครื่องคุณ

  • Listens on 127.0.0.1 only. Other devices on your network can't open it.
  • รับการเชื่อมต่อจาก 127.0.0.1 เท่านั้น เครื่องอื่นในเครือข่ายเปิดไม่ได้
  • Read-only: it reads the files Claude Code already writes and never changes your settings or hooks.
  • อ่านอย่างเดียว ใช้แค่ไฟล์ที่ Claude Code เขียนไว้อยู่แล้ว ไม่แตะ settings หรือ hooks ของคุณ
  • Nothing is sent anywhere, and your prompts never appear on screen.
  • ไม่ส่งข้อมูลออกไปที่ไหน และไม่แสดงข้อความที่คุณพิมพ์สั่ง Claude บนจอ

FAQ

Does it use my Claude tokens?เปลือง token ของ Claude ไหม

No. It only reads files on your disk. It never talks to Claude.

ไม่เปลืองเลย มันแค่อ่านไฟล์ในเครื่อง ไม่ได้คุยกับ Claude

Does it work on Linux or Windows?ใช้บน Linux หรือ Windows ได้ไหม

It's built and tested on macOS. On Linux the office works and tmux and Herdr panes can be focused, but it's less tested. Windows isn't supported yet.

ทำและทดสอบบน macOS บน Linux ตัวออฟฟิศใช้ได้ และคลิกไป pane ของ tmux กับ Herdr ได้ แต่ยังทดสอบไม่มาก ส่วน Windows ยังไม่รองรับ

Can I use another port?เปลี่ยนพอร์ตได้ไหม

Yes: PORT=8080 bun start. If you moved Claude's folder with CLAUDE_CONFIG_DIR, Deskbit follows it.

ได้ ใช้ PORT=8080 bun start และถ้าคุณย้ายโฟลเดอร์ของ Claude ด้วย CLAUDE_CONFIG_DIR ตัว Deskbit ก็จะตามไปอ่านที่นั่นเอง

What about Codex, Cursor or other agents?ใช้กับ Codex, Cursor หรือ agent อื่นได้ไหม

Claude Code only for now.

ตอนนี้รองรับเฉพาะ Claude Code
