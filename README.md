# Deskbit

A pixel office for your Claude Code sessions. Every session you run becomes a worker at a
desk, in a room for its git repo. See who's busy, who's waiting for your answer, and click
anyone to jump to their terminal. Runs on your Mac, read-only.

- **Website and live demo:** https://jrchanakarn.github.io/deskbit/
- **Download:** [latest release](https://github.com/JRChanakarn/deskbit/releases/latest)
- **Support:** https://ko-fi.com/jrchanakarn
