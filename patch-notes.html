What changed in each version. The latest download is always on GitHub.

แต่ละเวอร์ชันมีอะไรเปลี่ยนบ้าง ไฟล์เวอร์ชันล่าสุดดาวน์โหลดได้ที่ GitHub เสมอ

1.0.3 Latestล่าสุด

2026-10-30
  • Starting Deskbit while it's already running (for example from autostart) now says so and gives the address, instead of a port error. If another app holds the port, it tells you how to use a different one.
  • ถ้าเปิด Deskbit ซ้ำตอนที่มีตัวหนึ่งรันอยู่แล้ว (เช่น ตั้งให้เปิดเองตอนล็อกอิน) จะบอกว่าเปิดอยู่แล้วพร้อมลิงก์ แทน error เรื่องพอร์ต ถ้าพอร์ตถูกโปรแกรมอื่นใช้อยู่ จะบอกวิธีเปลี่ยนไปใช้พอร์ตอื่น

1.0.2

2026-10-30
  • When the Herdr window or a tmux client runs inside an Otty tab, clicking a worker now switches Otty to that tab, not just to Otty.
  • ถ้าหน้าต่าง Herdr หรือ tmux เปิดอยู่ในแท็บของ Otty คลิกตัวละครแล้ว Otty จะสลับไปที่แท็บนั้นให้เลย ไม่ใช่แค่เปิดแอป Otty ขึ้นมา

1.0.1

2026-10-30
  • Clicking a worker whose Herdr or tmux session isn't open in any window (no Herdr window, or a detached tmux session such as claude-squad's) now says so and copies the command that opens it (herdr, tmux attach -t …), instead of silently doing nothing.
  • คลิกตัวละครที่อยู่ใน Herdr หรือ tmux ซึ่งไม่ได้เปิดอยู่ในหน้าต่างไหน (ไม่มีหน้าต่าง Herdr เปิดอยู่ หรือเป็น tmux ที่รันเบื้องหลังแบบของ claude-squad) จะมีข้อความบอก และคัดลอกคำสั่งเปิด (herdr, tmux attach -t …) ให้ แทนที่จะเงียบไปเฉยๆ

1.0.0

2026-10-30
  • A pixel office for Claude Code: one room per git repo, one worker per running session, interns for subagents, a shared lounge for whoever is idle.
  • Workers type, read, browse, think at the whiteboard, and stand up with a red bubble when they need you. Bubbles show the tool and file, never your prompt.
  • Click a worker to jump to its terminal: the exact tab in Otty, the exact pane in Herdr or tmux, or the right app for Ghostty, iTerm2, Terminal, VS Code and others.
  • A ding when someone needs you, a chime when work is done.
  • English and Thai.
  • Runs on your Mac only (127.0.0.1), read-only.
  • ออฟฟิศพิกเซลสำหรับ Claude Code: หนึ่งห้องต่อหนึ่ง git repo หนึ่งตัวละครต่อหนึ่ง session ที่เปิดอยู่ subagent มาเป็นเด็กฝึกงาน และมีห้องพักรวมให้คนที่ว่างอยู่
  • ตัวละครนั่งพิมพ์ อ่าน ค้นเว็บ ยืนคิดที่ไวท์บอร์ด และลุกขึ้นพร้อมบับเบิลแดงเมื่อรอคุณอยู่ บับเบิลบอกเครื่องมือและไฟล์ที่ใช้ ไม่แสดงข้อความที่คุณพิมพ์
  • คลิกตัวละครเพื่อไปที่เทอร์มินัล: แท็บนั้นใน Otty, pane นั้นใน Herdr หรือ tmux หรือดึงแอปขึ้นมาสำหรับ Ghostty, iTerm2, Terminal, VS Code และอื่นๆ
  • มีเสียงเตือนเมื่อมีคนรอคุณ และเสียงเบาๆ เมื่องานเสร็จ
  • ภาษาอังกฤษและไทย
  • ทำงานบน Mac ของคุณเท่านั้น (127.0.0.1) และอ่านอย่างเดียว
